# Contributing to Lifex-AI

We welcome contributions from clinical engineers, security architects, and medical software developers.

---

## Code of Clinical Conduct
1. **Never violate the core axiom:** $AI \neq Doctor$.
2. **Never commit hardcoded clinical dummy identities.** Provide customizable models.
3. **Never bypass consent gates.** All patient data queries must pass through authorization and consent checks.
4. **All features require tests:** Ensure new endpoints and views are covered by the architecture test suite.
